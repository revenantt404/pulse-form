# PULSE/FORM — Jakarta 2027

Designed & built by **developer K**.

**Live Demo:** https://pulse-form-mu.vercel.app  
**Repository:** https://github.com/revenantt404/pulse-form

A fictional culture festival website concept built as a front-end showcase. It is intentionally framed as a real project / event brand rather than a personal portfolio.

## Concept

PULSE/FORM is a two-day collision of live sound, moving image, and late conversations in Jakarta. The visual language combines industrial wayfinding, analog scanlines, lime signal green, and editorial typography.

## Front-end details

- Responsive event landing page
- CSS-built event artwork, artist posters, venue map, and ticket cards
- Branded loading sequence with progress counter
- Scroll progress line and sticky glass navigation
- CSS motion system: orbiting geometry, scanline drift, floating artwork, reveal choreography, and hover states
- Desktop-only magnetic actions, cursor, artwork parallax, and 3D tilt
- Lineup filter interaction
- Day one / day two schedule switcher
- Mobile navigation
- Scroll reveal transitions, custom cursor, and subtle 3D tilt
- Semantic HTML and reduced-motion fallback
- No external assets or dependencies

## Run locally

```bash
python3 -m http.server 4173
```

Then visit `http://localhost:4173`.

## Personalize

The fictional content lives in `index.html`. Replace artist names, dates, venue details, email, and ticket prices if you want to present this as your own case study. Colors and layout tokens are at the top of `styles.css`.
